# Networking Portfolio

Hands-on networking study focused on routing, switching, and core network services. This repository brings together lab documents, network-simulation files, and technical reference notes.

**Current scope:** the repository contains learning materials and lab artifacts. Results, environment details, and verification evidence are not documented for every item, so files are presented as study work rather than production experience or verified deployments.

**Profiles:** [GitHub](https://github.com/shivprasadsabat) · [Connect on LinkedIn](https://www.linkedin.com/in/shivprasad-sabat)

## Areas of focus

- **Routing:** static routing, RIP, OSPF, and EIGRP
- **Switching:** VLANs, spanning tree, and router-on-a-stick
- **Network services:** DHCP, DNS, NTP, and Telnet access
- **Address translation:** NAT

These topics reflect the materials currently in the repository; they are not claims of professional experience.

Entries should identify their context (for example, simulation or physical lab), describe the goal and implementation, and distinguish expected behavior from tested results. Supporting files should be sanitized and linked from the relevant section. See the [lab template](labs/TEMPLATE.md) and [project template](projects/TEMPLATE.md) when adding work.
